# Extras

Seven lightweight 32l effects in one source file, each its own overlay module:
ROTARY (rotary speaker), RING (ring modulator), CRUSH (bit crusher), H-TREM
(harmonic tremolo), BIG PI (sustaining two-stage fuzz), BOOST (clean boost) and SWELL
(volume swell). See [controls, design and limits](../../docs/User%20Guide.md).
State stays per slot within FrostEffectState; no workspace. Host tested
(tests/test_extras.py); physical sound/CPU qualification pending.
