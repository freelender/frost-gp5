# PING

PING PONG DELAY: a stereo ping-pong delay. Echoes alternate between the left
and right outputs; WIDTH sets the spread. One delay line read at two points
(TIME up to 400 ms between echoes), the shared delay workspace and the stereo
side signal (engine/stereo.h). With OUTPUT MODE MONO, or when an amp, drive,
cab, pitch or dynamics block follows it, it plays as an ordinary mono delay.
TAIL as on the other delays. See [controls](../../docs/Effects%20list.md).
Host tested (tests/test_pingpong.py); physical sound/CPU qualification pending.
