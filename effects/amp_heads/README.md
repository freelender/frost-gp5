# Algorithmic amp heads

Seven original Frost behavioral models with local preamp, tone, power-stage
and supply histories. No NAM/capture files or cabinet processing. Add the
separate IR block after the head. See [controls, intended voices, evidence
and limits](../../docs/User%20Guide.md).

Deluxe, Twin, AC30 Top Boost, JC-120 clean, JCM800 2203 crunch,
Dual Rectifier Modern lead and EVH 5150III 6L6 lead are the starting voices.
These are compact approximations inspired by the named amps, not measured
matches, circuit solvers, manufacturer implementations or endorsements.

Controls: GAIN, BASS, MID, TREBLE, BRIGHT/CUT/PRESENCE, MASTER, LEVEL.
Each instance uses 120 bytes, the whole unchanged 120-byte state union.
All seven types share one relocatable module and need no external workspace.
