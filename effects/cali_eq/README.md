# CALI EQ

CALI 5-BAND EQ: a five-slider graphic EQ in the style of the classic
California lead amp's EQ, at 80, 240, 750, 2200 and 6600 Hz (+/-12 dB each),
plus an output LEVEL (+/-12 dB). Broad 1.6-octave bands built from the same
Regalia-Mitra sections as EQ-7. Place it after an amp for the classic "V"
(80 and 6600 up, 750 down). See [controls](../../docs/Effects%20list.md).
State stays per slot within FrostEffectState; no workspace. Host tested
(tests/test_cali_eq.py); physical sound/CPU qualification pending.
