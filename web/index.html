    About training audio

    Use the official NAM input.wav: real guitar and bass recordings, the same file NAM captures are trained on. In our tests it gave clearly closer models on crunch and high-gain amps. Download it free from the Neural Amp Modeler website (the "input.wav" link), then choose it here. Frost can't include it. The file stays on your computer; conversion takes about 30% longer with it.

    Conversion takes a few minutes. A converted model is an approximation of the capture.

        Saved sounds

        Presets.

        Load a saved sound to play it, reorder, rename or delete presets, and back up everything on the pedal to a file. Loading replaces unsaved live edits. Song parts reference preset numbers: moving, replacing or deleting a preset changes what those parts play.

        On the pedal
        Connect to read the pedal.
          Backup

          One file with every preset, AMP model and cabinet. Restoring replaces them all on the pedal.

          Single presets

          Download one preset as a file with its row's Download button, or import a preset file into a preset number. The file keeps the effects and settings and carries the AMP models and cabinets the preset uses; on import you choose the MODEL and CAB numbers to store them at.

          To save the current sound, use Save to pedal in the Live editor, or on the pedal: PRESETS → SAVE.
          Install & recover

          Firmware.

          Install Frost, or go back to Valeton's firmware. Nothing is installed until you confirm.

          Coming from Valeton stock firmware?Start here: plug in your powered GP-5 with a USB data cable, back up stock presets in Valeton's editor, then close that editor. Use Install Frost below, or choose your Frost .bin file. You do not need to press Connect GP-5 first; that button connects the live editor after Frost is installed.
          ⚠ Keep the pedal connected and poweredInstalling replaces the pedal's firmware and takes about 90 seconds. The pedal enters update mode by itself. The factory loader is never overwritten, so an interrupted install can always be repeated.

          Install from a file

          Choose a Frost firmware file (.bin from a Frost release) to install or update Frost, or the official GP-5 firmware downloaded from Valeton to go back to stock. The page checks the file and tells you what it is before anything is installed. Frost cannot ship Valeton's firmware.

          About Frost.
          Custom firmware for the Valeton GP-5: a six-slot effects chain with AMP models, cabinet IRs, presets, tuner and drop tune.
